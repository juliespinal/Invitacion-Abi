# Abi — Mis Quince

Invitación web para los 15 años de Abi. Ver [CLAUDE.md](./CLAUDE.md) para los requisitos
completos del proyecto y [docs/design-system.md](./docs/design-system.md) para el sistema
visual (Etapa 1, aprobado).

## Stack

- Vite + TypeScript (vanilla, sin framework de UI)
- Tailwind CSS v4
- GSAP + ScrollTrigger + Lenis (animación/scroll)
- Phosphor Icons
- Google Apps Script + Google Sheets (backend de confirmaciones)
- Deploy: GitHub Pages

## Desarrollo

```bash
npm install
npm run dev
```
